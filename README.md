# BabyCam for Home Assistant

A private, local-only baby monitor. A spare phone's browser becomes the camera. You watch and listen from the Home Assistant sidebar or any browser on your Wi-Fi, and noise alerts reach your phone through Home Assistant notifications.

## Install

1. In Home Assistant, go to **Settings › Add-ons › Add-on Store**, open the **⋮** menu, then **Repositories**.
2. Add this repository's URL.
3. Install **BabyCam**, then follow its **Documentation** tab.
